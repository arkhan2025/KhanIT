# Khan IT Website - React Version

This is the **ReactJS implementation** of the Khan IT digital marketing website, featuring modern web development techniques and interactive UI components.

## Features
- Component-based architecture using ReactJS
- Dynamic navigation with dropdown menus
- Interactive sections for services and about
- Fully responsive across desktop, tablet, and mobile
- Professional styling using CSS modules

## Technologies Used
- ReactJS
- HTML5, CSS3
- Google Fonts: DM Sans, Inter
- Responsive design techniques: Flexbox, CSS Grid
