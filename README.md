# Khan IT Website - Vanilla JavaScript Version

This is the **Vanilla JavaScript implementation** of the Khan IT digital marketing website, featuring all interactive features without any frontend frameworks.

## Features
- Fully built with HTML, CSS, and Vanilla JavaScript
- Mobile-friendly and responsive
- Interactive navigation and services dropdown
- Modern card-based layout for services and about sections
- Professional styling with Google Fonts and CSS effects

## Technologies Used
- HTML5, CSS3
- Vanilla JavaScript
- Google Fonts: DM Sans, Inter
- Responsive design techniques: Flexbox, CSS Grid
